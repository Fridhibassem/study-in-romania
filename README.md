# Study in Romania

This is a simple landing page for a service that helps students who want to study in Romania.

The page explains the main idea of the service, the type of support offered, and the steps related to university admission, document preparation, and student visa guidance.

## Project type

This project is a static website built with:

- HTML
- Tailwind CSS CDN
- Font Awesome icons
- Google Fonts

There is no backend in this project. The website can be opened directly in the browser.

## How to open it

Open the file:

```text
index.html
```

or double-click it from the project folder.
